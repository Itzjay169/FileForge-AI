## 2. Universal File Registry (`@fileforge/file-registry`)

Rather than hardcoding format logic across different UI screens and backend workers, FileForge AI implements a centralized **File Type Registry**.

Each registered format contains:
- **`extension`**: Canonical extension without leading dot.
- **`category`**: One of 12 strict domain categories (`documents`, `images`, `video`, `audio`, `spreadsheets`, `presentations`, `code`, `archives`, `executables`, `databases`, `fonts`, `cad3d`).
- **`mimeTypes`**: Official and alternate MIME types.
- **`magicBytes`**: Hexadecimal byte signatures used to prevent extension spoofing and polyglot exploits.
- **`uploadAllowed`**: Gatekeeping check.
- **`previewSupported`**: Enables in-browser side-by-side preview.
- **`compressionSupported`**: Signals algorithmic availability.
- **`conversionTargets`**: Valid destination formats.
- **`lossWarnings`**: Granular transparency reports indicating which attributes (e.g. layers, macros, vector paths) are dropped during conversion.
- **`riskLevel`**: `LOW`, `MEDIUM`, `HIGH`, `CRITICAL` (determines container isolation level).
- **`requiredProcessor`**: Routing key to the designated worker engine.

## 3. Sakuga Animation System

Inspired by the open-source **Sakuga VFX** philosophy, ordinary controls react with expressive anime-inspired physics:
1. **Squash & Stretch**: Buttons compress on press (`scaleY: 0.88`, `scaleX: 1.08`) and overshoot on release with spring dynamics.
2. **Impact Frames**: Clicking buttons or completing conversions emits a single-frame white overlay flash (`opacity: 0.75 -> 0` in 150ms).
3. **Teardrop Sliders**: Slider thumbs dynamically stretch in the direction of velocity while dragging, with speed-lagged motion values.
4. **Energy Shimmer**: Progress bars display a traveling plasma stripe during processing that locks into solid emerald green upon 100% completion.
5. **Accessibility Fallback**: The design system strictly detects `prefers-reduced-motion`. When active, particle emitters and heavy spring distortions are bypassed while maintaining snappy state transitions.

## 4. AI Content & Watermark Transparency Architecture

The transparency engine is purpose-built for legal authenticity and C2PA provenance:
- **Scanner Phase**: Extracts IPTC, XMP, EXIF, and C2PA manifest claims.
- **Provenance Verification**: Verifies digital cryptographic signatures to show whether the asset was generated by Midjourney, DALL-E, Stable Diffusion, or camera sensors.
- **Anti-Evasion Policy**: Plagiarism evasion, removal of copyright notices, or bypassing watermark detection on third-party content is strictly prohibited.
- **Verified Ownership Flow**: Content creators can remove visible watermarks from their own content only after confirming copyright declaration with an immutable database audit log.
