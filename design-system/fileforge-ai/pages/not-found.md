# Page Design Override: Custom 404 Page (`/not-found`)

## Purpose
Branded, helpful, friendly anime-styled error recovery page with zero dead ends.

## Features
- Bold headline: "404 — Frame Not Found".
- Friendly explanation: "The file, route, or frame you're looking for was moved, renamed, or converted into another dimension."
- Search input with `<sakuga-input>` to find tools directly.
- Quick navigation buttons to: Home, Studio, Convert, Formats Explorer, Help Center, Contact.
- Dynamic anime spark animation and error illustration.
